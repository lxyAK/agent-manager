# Agent Manager v2 产品需求文档

## 产品背景

Agent Manager 是一个桌面端 AI 编码 Agent 管理工具，支持同时运行 Claude Code、OpenAI Codex、OpenCode 等多个 AI Agent。

当前版本仅提供多终端标签管理能力，用户反馈核心问题是：

1. **多 Agent 同时运行时，不知道每个 Agent 在干什么** — 需要逐一切换查看，效率低下
2. **多 Agent 协作需要手动复制粘贴** — 一个 Agent 的输出要人工搬运到另一个 Agent

## 功能一：Agent 状态感知

### 用户场景

开发者同时启动了 3 个 Agent 分别处理不同任务。他切换到浏览器查资料，5 分钟后回来，需要快速判断：
- 哪些 Agent 已经完成，可以查看结果
- 哪些 Agent 卡住等待输入，需要我去响应
- 哪些 Agent 出错了，需要干预
- 哪些 Agent 还在正常工作

### 需求描述

系统自动识别每个 Agent 会话的当前工作状态，在侧边栏会话列表和标签栏上以视觉方式实时展示。

### 状态定义

| 状态 | 含义 |
|---|---|
| 空闲 | Agent 未启动、已退出、或等待接受新命令 |
| 思考中 | Agent 正在分析代码、规划方案、处理任务 |
| 写入中 | Agent 正在创建或修改文件 |
| 等待输入 | Agent 需要用户确认操作、选择选项或回答问题 |
| 错误 | Agent 遇到了错误 |

### 显示要求

- 侧边栏每个会话条目左侧有状态指示器，不同状态用不同颜色区分
- "思考中"状态需要动态效果，让用户一眼能看出 Agent 正在工作
- 标签栏也需展示状态信息
- 状态变化应实时响应，无明显延迟感

### 识别规则

需覆盖以下 Agent 的输出特征：
- Claude Code
- OpenAI Codex
- OpenCode

#### 空闲判断
- Agent 任务完成回到命令等待状态
- Agent 进程已退出
- 连续一段时间无任何输出且当前不是"等待输入"或"错误"状态

#### 思考中
- Agent 正在读取文件、分析代码、规划操作
- 终端有持续输出但未进行文件修改操作

#### 写入中
- Agent 正在创建新文件或编辑已有文件

#### 等待输入
- Agent 向用户提出确认问题（如是否执行某操作）
- Agent 提供了多个选项让用户选择
- Agent 等待用户回答问题

#### 错误
- Agent 输出中包含错误信息

### 优先级与兜底

- 错误状态优先级最高，一旦识别到错误应保持该状态直到 Agent 恢复正常工作
- 无法明确判断时，默认视为"思考中"（宁可多显示工作状态，也不要误报空闲）
- 超时回退：Agent 停止输出一段时间后，从"思考中"或"写入中"回退为"空闲"，但"等待输入"和"错误"不自动回退

## 功能二：跨会话协作

### 用户场景

开发者让 Agent A 分析一个 bug，Agent A 输出了分析结果和错误堆栈。开发者想把这个结果直接发给 Agent B 让它修复代码。当前做法是手动选中、复制、切换标签、粘贴——多次操作，容易打断思路。

### 2.1 选中发送

#### 需求描述

用户在一个 Agent 终端中选中文字后，可以快速将选中内容发送到另一个 Agent 会话。

#### 交互方式

**右键菜单：**
- 在终端中选中文字后右键，弹出自定义菜单
- 菜单列出当前所有活跃的 Agent 会话（排除当前会话自身）
- 点击某个会话名称，选中内容自动输入到该会话终端
- 菜单同时提供"复制到剪贴板"选项
- 未选中文字时，右键行为不变或仅显示基础选项

**菜单关闭：**
- 点击菜单项后自动关闭
- 点击菜单外部区域关闭
- 按 Escape 关闭

#### 快捷键

支持键盘快捷键快速发送，避免鼠标操作：
- 使用 Ctrl+Shift+数字键 的形式，数字对应会话的序号
- 发送后自动切换到目标会话

### 2.2 文件冲突提示（增强功能，可后续迭代）

#### 用户场景

开发者让 Agent A 和 Agent B 同时在同一个项目目录下工作。Agent A 修改了 `src/main.js`，但 Agent B 不知道这个变化，可能基于旧版本代码继续工作，导致冲突或覆盖。

#### 需求描述

当多个 Agent 会话在相同或嵌套的工作目录下运行时，如果某个会话产生了文件变更，系统通知其他会话的用户。

#### 显示方式

在目标会话区域以非阻塞的通知方式展示，包含：
- 哪个文件被修改
- 哪个 Agent 修改的
- 大致的时间

#### 约束

- 不需要检测具体的文件内容差异，只通知"文件有变化"即可
- 同一会话自身的文件修改不通知自己
- 只关注常见代码文件类型
- 应用退出时正确释放所有监控资源

## 交付标准

### 状态感知

- [ ] 启动任意 Agent 后，侧边栏和标签栏正确显示其工作状态
- [ ] Agent 完成任务回到等待状态时，指示器恢复为空闲
- [ ] Agent 遇到错误时，指示器变红并保持直到恢复
- [ ] Agent 等待用户输入时，指示器明确区分于"正在工作"状态
- [ ] 多个 Agent 同时运行时，各自状态独立且准确
- [ ] 状态切换无明显卡顿

### 选中发送

- [ ] 选中文字后右键菜单正确列出其他活跃会话
- [ ] 点击菜单项后内容成功输入到目标终端
- [ ] 快捷键发送功能正常
- [ ] 各种边界情况处理正确：无选中文字、只有一个会话、会话已退出等
